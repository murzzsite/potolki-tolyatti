# Потолки Тольятти

Лендинг: изготовление и монтаж натяжных потолков в Тольятти, продажа комплектующих.

- Один мотив — круг (светильник в потолке): диск в hero, маркеры в калькуляторе, кнопки, маски фото, подвал.
- Живой калькулятор по прайсу клиента (потолок 550 ₽/м², заглушка 150 ₽/м.п., светильник 500 ₽, люстра 1000 ₽, карниз 850 ₽/м.п.), расчёт уходит в заявку.
- Заявки: Cloudflare Worker → Telegram (ref в script.js).
- Фото: Wikimedia Commons, подписи и лицензии в подвале и в assets/credits.json.

Заглушки, которые нужно подтвердить у клиента: название компании, контакты (телефона и мессенджера нет), входит ли полотно в 550 ₽/м², ассортимент и цены комплектующих.
